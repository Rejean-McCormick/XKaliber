# Checklist MVP

## Produit

- [ ] Une personne peut comprendre ce que XKaliber mesure.
- [ ] Une personne peut consentir avant l’épreuve.
- [ ] Une personne peut passer une épreuve complète.
- [ ] Une personne peut recevoir un Profil de Calibre.
- [ ] Une personne peut comprendre les limites du résultat.
- [ ] Une personne peut demander une révision.

## Évaluation

- [ ] Le système peut démarrer à un niveau estimé.
- [ ] Le système peut augmenter la difficulté.
- [ ] Le système peut réduire ou stabiliser la difficulté.
- [ ] Le système peut détecter un effet plafond.
- [ ] Le système peut produire une marge de confiance.
- [ ] Le système peut distinguer niveau confirmé et niveau exploré.

## CertifiKation

- [ ] Le système peut générer un Sceau CertifiKation.
- [ ] Le sceau contient des limites d’usage.
- [ ] Le sceau contient une durée de validité.
- [ ] Le sceau peut être contesté ou expiré.

## Gouvernance

- [ ] Les règles sont versionnées.
- [ ] Les items ont un statut de validation.
- [ ] Les interventions humaines sont tracées.
- [ ] Les changements de seuil sont documentés.
- [ ] Les usages dans EkoH ou SmartVote sont limités.
