# Exemple — session d’évaluation

## Contexte

Une personne postule pour un rôle qui demande une compétence d’analyse de données de niveau intermédiaire.

## Scan initial

Le parcours KonnectED indique une expérience de base. Le système démarre au niveau 2.

## Déroulement

### Bloc 1 — Niveau 2

Résultat : réussite élevée.

Interprétation : niveau 2 probablement maîtrisé.

Action : passer au niveau 3.

### Bloc 2 — Niveau 3

Résultat : réussite solide, explication correcte des limites.

Interprétation : niveau 3 confirmé.

Action : explorer le niveau 4.

### Bloc 3 — Niveau 4

Résultat : performance partielle. La personne voit certains biais, mais généralise trop vite.

Interprétation : niveau 4 partiellement démontré.

Action : ajouter une tâche de précision.

### Bloc 4 — Niveau 4

Résultat : performance moyenne, mais amélioration après consigne structurée.

Interprétation : niveau 4 non certifié, mais potentiel présent.

## Sortie

Calibre validé : niveau 3  
Portée maximale explorée : niveau 4  
Confiance : moyenne-haute  
Recommandation : CertifiKation niveau 3 ; formation ciblée avant niveau 4.
