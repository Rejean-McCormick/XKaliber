# Périmètre MVP

## Inclus

- domaines et compétences ;
- niveaux de difficulté ;
- banque d’items simple ;
- session d’évaluation ;
- adaptation par blocs ;
- Profil de Calibre ;
- Sceau CertifiKation minimal ;
- journal d’audit ;
- consentement ;
- explication du résultat ;
- export conceptuel vers CertifiKation et K-Port.

## Exclu du MVP

- marketplace d’évaluations ;
- gestion complète des cours ;
- pondération SmartVote active ;
- score EkoH automatisé ;
- intégration directe XKaliber → EkoH ou XKaliber → SmartVote ;
- correction avancée par IA ;
- épreuves de haute sécurité ;
- surveillance vidéo ;
- intégration RH complète ;
- identité décentralisée définitive ;
- certifications réglementées.

## Hypothèse MVP

Une première version peut fonctionner avec :

- quelques domaines ;
- une banque limitée d’items ;
- des règles d’adaptation simples ;
- des profils générés de manière explicable ;
- un processus de révision humain.

## Mesures de succès MVP

- Les utilisateurs comprennent mieux leur niveau.
- Les évaluateurs trouvent le profil plus utile qu’une note.
- Les effets plafond sont détectés.
- Les personnes peuvent contester ou demander un recalibrage.
- Les preuves exportées sont lisibles et limitées au bon contexte.
