# Exigences d’audit

## Ce qui doit être traçable

- version de l’épreuve ;
- version des règles d’adaptation ;
- consentement ;
- identité du domaine ;
- items présentés ;
- niveaux de difficulté ;
- réponses ou productions ;
- corrections ;
- interventions humaines ;
- anomalies ;
- résultat final ;
- export CertifiKation ;
- partage vers d’autres modules ;
- appels et corrections.

## Ce qui doit être explicable

- pourquoi un niveau a été confirmé ;
- pourquoi un niveau supérieur n’a pas été confirmé ;
- pourquoi le système a augmenté ou réduit la difficulté ;
- quelles limites s’appliquent ;
- comment le résultat peut être contesté.

## Ce qui doit être versionné

- domaines ;
- compétences ;
- items ;
- niveaux ;
- seuils ;
- règles ;
- profils ;
- preuves ;
- politiques d’usage.
