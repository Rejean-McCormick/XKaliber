# Carte des modules conceptuels

## 1. Assessment Designer

Permet de définir :

- domaines ;
- compétences ;
- niveaux ;
- types d’épreuves ;
- critères de réussite ;
- conditions de certification.

## 2. Item Bank

Contient les items, tâches ou scénarios évaluatifs.

Chaque item doit avoir :

- domaine ;
- compétence ;
- difficulté ;
- durée estimée ;
- critères ;
- risques de biais ;
- version ;
- statut de validation.

## 3. Adaptive Engine

Choisit la prochaine tâche selon :

- performance actuelle ;
- incertitude ;
- niveau visé ;
- niveau exploré ;
- diversité des tâches ;
- règles de fatigue ;
- contraintes de temps.

## 4. Evaluation Session

Gère le déroulement :

- démarrage ;
- consentement ;
- consignes ;
- réponses ;
- pauses ;
- incidents ;
- fin de session.

## 5. Scoring and Interpretation

Transforme la performance en lecture utile :

- niveau confirmé ;
- marge de confiance ;
- erreurs récurrentes ;
- forces ;
- zones à approfondir ;
- recommandation.

## 6. Caliber Profile

Génère le rapport lisible.

## 7. CertifiKation Export

Produit une preuve exportable, avec traces et limites.

## 8. Governance Log

Conserve :

- règles utilisées ;
- versions ;
- exceptions ;
- interventions humaines ;
- appels ;
- corrections.

## 9. Integration Gateway

Définit les échanges avec :

- KonnectED ;
- CertifiKation ;
- EkoH ;
- SmartVote ;
- Konnaxion ;
- systèmes externes autorisés.
