# Flux UX principaux

## Flux 1 — Passer une épreuve

```text
Accueil
→ Choix du domaine
→ Consentement
→ Scan initial
→ Épreuve adaptative
→ Résumé provisoire
→ Profil de Calibre
→ Options : sauvegarder, partager, contester, recalibrer
```

## Flux 2 — Créer une épreuve

```text
Créer un domaine
→ Définir les compétences
→ Définir les niveaux
→ Ajouter des items
→ Définir les critères
→ Tester l’épreuve
→ Soumettre à validation
→ Publier
```

## Flux 3 — Générer une CertifiKation

```text
Profil de Calibre
→ Vérifier seuil de certification
→ Générer Sceau CertifiKation
→ Ajouter au portfolio KonnectED
→ Définir partage public/privé
→ Planifier recalibrage
```

## Flux 4 — Réviser un résultat

```text
Profil contesté
→ Motif de contestation
→ Revue des traces
→ Intervention humaine
→ Décision de maintien/correction/reprise
→ Journal d’audit mis à jour
```

## Flux 5 — Alimenter EkoH

```text
Profil de Calibre
→ Consentement
→ Résumé borné par domaine
→ Contrôle des limites
→ Signal envoyé vers EkoH
→ Affichage explicable dans le profil Konnaxion
```
