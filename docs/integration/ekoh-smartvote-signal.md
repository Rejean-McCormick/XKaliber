# Signal vers EkoH et SmartVote

## Principe

XKaliber peut contribuer à la crédibilité par domaine, mais ne doit jamais créer une autorité globale.

## Signal EkoH minimal

Un signal envoyé vers EkoH devrait contenir :

- domaine ;
- compétence ;
- niveau confirmé ;
- date ;
- confiance ;
- durée de validité ;
- source ;
- limites ;
- consentement ;
- statut.

## Ce qu’il ne faut pas envoyer par défaut

- réponses brutes ;
- temps détaillés ;
- erreurs personnelles sensibles ;
- commentaires privés ;
- données non nécessaires ;
- interprétations hors domaine.

## Usage SmartVote

SmartVote peut utiliser des signaux de compétence seulement si :

- le domaine du vote correspond au domaine validé ;
- les règles de pondération sont publiques ;
- les lectures non pondérées restent visibles ;
- la personne sait que le signal est utilisé ;
- la communauté peut contester la règle ;
- le signal est limité dans le temps.

## Phrase clé

**XKaliber peut éclairer la gouvernance ; il ne doit pas la capturer.**
