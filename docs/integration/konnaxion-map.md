# Intégration avec Konnaxion

## Relation entre les modules

```text
Konnaxion
└─ KonnectED
   └─ CertifiKation
      └─ XKaliber
```

## Rôles

### KonnectED

Développe les compétences par parcours, cours, activités et portfolio.

### XKaliber

Mesure le calibre réel par épreuve adaptative.

### CertifiKation

Atteste une compétence confirmée.

### EkoH

Reçoit éventuellement un signal borné par domaine, avec consentement et limites.

### SmartVote

Peut utiliser certains signaux de compétence dans des lectures de gouvernance, si les règles publiques le permettent.

### Konnaxion

Rend la Table ronde opérante : apprentissage, compétence, délibération, décision et action peuvent se relier.

## Principe d’échange

XKaliber ne doit pas partager plus que nécessaire.

| Destination | Donnée recommandée |
|---|---|
| KonnectED | profil complet ou pédagogique |
| CertifiKation | niveau confirmé et preuve |
| EkoH | signal résumé par domaine |
| SmartVote | indicateur gouverné, non brut |
| Konnaxion public | uniquement si consentement |

## Phrase d’intégration

**XKaliber transforme la performance en preuve structurée. CertifiKation transforme cette preuve en reconnaissance. Konnaxion transforme la reconnaissance en capacité collective.**
