# Contribuer à XKaliber

## Types de contributions utiles

- amélioration du vocabulaire produit ;
- définition de domaines de compétence ;
- rédaction de scénarios utilisateurs ;
- conception d’épreuves ;
- règles d’équité ;
- modèles de profil ;
- exemples de rapports ;
- critères d’intégration avec CertifiKation, KonnectED, EkoH ou SmartVote.

## Règles de contribution

1. Écrire clairement.
2. Éviter le jargon inutile.
3. Ne pas imposer une technologie précise dans les documents de base.
4. Toujours préciser le domaine concerné.
5. Distinguer preuve, interprétation et décision.
6. Ne jamais proposer un score universel de personne.
7. Prévoir l’explication du résultat pour la personne évaluée.

## Format recommandé pour une proposition

```text
Titre :
Problème :
Proposition :
Domaine concerné :
Effet sur l’évaluation :
Effet sur la personne évaluée :
Effet sur CertifiKation :
Risques :
Mesures de protection :
```

## Décisions

Toute décision structurante doit être ajoutée dans le dossier `decisions/` sous forme de décision datée.
