# Décision 0002 — Départ agnostique technologiquement

## Statut

Acceptée comme base de départ.

## Décision

Ne pas choisir de langage, framework, base de données ou fournisseur dans le dépôt initial.

## Raison

Le risque principal au départ n’est pas technique. Il est conceptuel :

- mauvaise définition des compétences ;
- mesure opaque ;
- usage abusif des résultats ;
- confusion entre certification et score ;
- intégration prématurée à la gouvernance.

## Conséquence

Le dépôt démarre par :

- documents produit ;
- modèles conceptuels ;
- contrats neutres ;
- scénarios ;
- principes de gouvernance ;
- critères d’acceptation.

Les choix techniques viendront après validation du modèle.
